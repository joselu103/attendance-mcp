# Triage Labels

Use the default five-label vocabulary when triaging repository work:

- `bug` for incorrect behavior.
- `documentation` for agent, user, or contract documentation.
- `enhancement` for approved product capability.
- `question` for a decision or missing information.
- `security` for a security, privacy, or credential-handling concern.

Apply labels to describe the work, not to imply priority, deployment readiness,
or authorization.
